# 健康科普｜吃药不喝酒，喝酒不吃药

> 更新时间：2026-09-17 (UTC+8)

“吃药不喝酒，喝酒不吃药”，日常生活中，我们常常会听到这样的劝解语。那么究竟药与酒同服会产生怎样的危害呢？吃什么药是绝对禁止饮酒的呢？喝了酒又需要多长时间才能吃药呢？吃了药多长时间才能饮酒？……相信许多朋友会有以上的疑问，那么今天这则用药科普将会给你答案，一起来学习吧。

 

 
**  小知识：**饮用酒的主要成分为乙醇，即酒精，属微毒类化合物，是中枢神经抑制剂。研究发现，饮酒后，酒精可与许多服用的药物产生药物相互作用，使药效降低、增强或发生不良反应，更有甚者会导致毒性反应的出现，其中较为严重的不良反应为“双硫仑样”反应。

**一、什么是双硫仑样反应**

双硫仑样反应是指患者使用头孢菌素类等药物后饮酒出现面部潮红、大汗淋漓、头痛、头晕、口干、恶心、呕吐、胸痛等症状，严重者出现急性心力衰竭、呼吸困难、惊厥及死亡等, 严重威胁患者生命安全。

**  小知识：**乙醇进入体内后，先在肝脏内经乙醇脱氢酶作用转化为乙醛，乙醛再经醛糖氧化还原酶作用转化为乙酸，乙酸进入枸橼酸循环，最后转变为水和二氧化碳排出。而双硫仑可抑制醛糖氧化还原酶，使乙醛不能氧化为乙酸，致使体内乙醛浓度升高，产生不适。

二、**双硫仑样反应的**症状

患者出现面部潮红、头痛、头晕、烦躁不安、恶心、呕吐、幻觉、嗜睡。比较严重的表现有：胸闷、气促、呼吸困难、血压下降至60-70/30-40mmHg，并伴有意识丧失，心率增快，心前区疼痛，原有冠心病或潜在冠心病者易引起冠脉痉挛，造成心肌缺血，部分病历心电图示 ST-T 改变等。

严重者可因脑水肿、颅内压增高出现短暂意识障碍、失语、四肢肌力降低。反应的严重程度和饮酒量成正比。

** 小知识：**饮用白酒、啤酒、含酒精饮料等反应重，**用药期间饮酒**较**停药后饮酒**反应重，如果是不会饮酒者，反应会更严重，这种反应一般在用药与饮酒后**15-30分钟**发生。

**三、哪些药物会引起双硫仑样反应**

**1.头孢菌素类药物：**头孢哌酮、头孢哌酮舒巴坦、头孢曲松、头孢唑林、头孢美唑、头孢米诺、拉氧头孢、头孢甲肟、头孢孟多等。其中以**头孢哌酮**致双硫仑样反应的报告最多、最敏感，有患者在使用**头孢哌酮**后吃酒心巧克力、服用藿香正气水，甚至仅用酒精处理皮肤也会发生双硫仑样反应。

**2.硝咪唑类药物：**甲硝唑（灭滴灵）、替硝唑、奥硝唑、塞克硝唑。

**3.其他抗菌药：**呋喃唑酮（痢特灵）、氯霉素、酮康唑、灰黄霉素等。

**4.其他类：**感冒药、 降糖药、糖皮质激素、抗过敏药以及一些抗精神病药。

**5、非甾体抗炎药：**对于服用这类药物用于解热镇痛的患者，应当注意限制酒精的摄入。如阿司匹林及水杨酸类药物，有导致胃黏膜损伤的可能，药与酒同服，胃肠道出血与溃疡的风险倍增。此外，酒后服用对乙酰氨基酚、布洛芬可增加其对于肝脏的毒性，故也不宜同服。

**服用中药时能否喝酒？**

答案当然是否定的。服用中药期间饮酒同样会影响药物疗效甚至造成不良后果，如服用的是收敛固涩类药，会在喝酒后随酒性发散，不仅起不到治疗作用，反而会对人体造成伤害。酒性燥热，容易伤阴动火，耗散正气，所以中医有：酒使气散之说。因此服用中药期间不宜饮酒。 **四、以下这些头孢类药物不会引起双硫仑样反应**

   双硫仑样反应虽然可怕，我们也无需“谈虎色变”，不是所有的抗菌药物都会产生双硫仑样反应。如：头孢噻肟、头孢他啶、头孢磺啶、头孢唑肟、头孢克肟、头孢拉定、头孢克洛等，因不含甲硫四氮唑基团或甲硫三嗪侧链，在应用期间饮酒不会引起双硫仑样反应。

      

**小知识：以下药物与酒相互作用引起的不良反应须谨慎**

镇静催眠类药 + 酒 = 致命组合

头孢类 + 酒 = 毒药

多西环素 + 酒 = 降低药效

抗癫痫类药物 + 酒 = 降低药效

非甾体抗炎药 + 酒 = 消化道出血

甲氨蝶呤、感冒药 + 酒 = 肝衰竭

抗心绞痛 + 酒 = 头痛、休克

降糖药 + 酒 = 低血糖、双硫仑样反应

吩噻嗪类 + 酒 = 不能耐受

## **五、防治措施**

一旦出现双硫仑样反应，应及时停药和停用含乙醇制品，轻者可自行缓解，缓解所需时间为0.5-12h，较重者需吸氧及对症治疗。对双硫仑样反应严重及过敏性休克患者应立即采取抢救措施，因此一旦发生严重反应切记要及时送医。

药物治疗：给予地塞米松，并根据病情轻重和症状给予相应的药物治疗；恶心、呕吐者给予胃复安；嗜睡、意识不清者给予纳洛酮。

## **六、使用头孢类药物多久可以饮酒？**

   要了解这个问题，首先要学习一下半衰期的概念。药物都有半衰期，它是指血浆中药物浓度下降一半所需要的时间。每种药物的半衰期不一样，一般情况下药物进入体内经过五到七个半衰期就基本代谢完，不会再发生作用，因此建议停药后2周再喝酒。

  ** 药物的半衰期、药物使用注意事项在药品说明书中能查询到，因此，药师提醒大家，使用药物前应该仔细阅读说明书，获得更多的安全用药知识。**

**七、饮酒后多久可以使用头孢类药物？**
这个问题和前面的问题很容易混淆，这需要考虑人体多久才能代谢完饮用的酒。
研究发现，从消化道被吸收的酒，90%-98%自门脉进入肝脏, 并通过肝脏被代谢。70 kg 体重的成年人在1h内可以处理 7g纯酒精。这个量相当于60mL日本清酒, 200mL啤酒或20mL威士忌的酒精含量。而对于酒精处理能力很强的善饮者来讲则 1 kg 体重1h可处理150-180mg 的纯酒精。成年男子一昼夜对酒的氧化代谢处理量限于 8 瓶 633 mL 容量的啤酒。如果在1h内连续饮用3瓶啤酒, 那么酒力对身体的影响待完全消失得需约9h, 即使是善饮者亦需6-7h。
值得注意的是，人体对于酒精的代谢能力因饮酒年龄、酒种、酒度、饮酒方式及饮酒者身体状况而异，也就是说，“酒后多久能使用头孢类药物”，因人而异。**一般建议酒后3天内是不可以使用可以导致双硫仑样反应的头孢菌素及其他药物（如甲硝唑、头孢米诺、呋喃唑酮等）。当然，换用其他抗菌药物是更安全的选择。**（部分内容参考来源 药事网 李征洋 “酒后用头孢”和“头孢后饮酒”，效果大不同）
